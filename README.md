# Планер Студента — 12 Группа

Статический сайт-планер: расписание пар (недели А/Б), звонки, календарь задач,
заметки к парам, врезки портала «Фемида» и электронной библиотеки.
Работает оффлайн (PWA), поддерживает синхронизацию между устройствами (JSONBin.io).

## Состав файлов

| Файл | Назначение |
|------|------------|
| `index.html` | Весь сайт (разметка, стили, логика) |
| `manifest.json` | Манифест PWA — чтобы сайт можно было «установить» на телефон |
| `sw.js` | Service Worker — оффлайн-кэш |
| `icon.svg` | Иконка приложения |

## Возможности

- **Расписание** на неделю с автоматическим определением недели «А/Б», подсветкой
  сегодняшнего дня и идущей пары, заметками к каждой паре (ДЗ, дедлайны)
- **Звонки** — с индикатором текущей пары
- **ДЗ** — домашние задания по предметам с дедлайнами: группы «Просрочено /
  Сегодня / Завтра / Позже / Выполнено», красный бейдж с числом несданных
- **Группа** — доска объявлений, синхронизируется между всеми у кого настроен
  JSONBin (максимум 50 последних)
- **Задачи** — личный планер по дням с календарём
- **Замены и отмены пар** — отмена, замена предмета или доп. пара: применяется
  в расписании у всей группы (синхронизируется), видна пометка ОТМЕНЕНА/ЗАМЕНА/ДОП. ПАРА
- **Пропуски** — отметка тапом по иконке в карточке пары, статистика по предметам
- **Оценки** — журнал оценок с автоматическим средним баллом по предметам и общим GPA
- **Сессия** — вкладка-заготовка под экзамены: мотивация на время семестра,
  каркас списка экзаменов (хранилище и синхронизация уже подключены —
  останется внести даты)
- **Помодоро-таймер** — фокус 25 мин / перерыв 5 мин, круг из 4 циклов →
  длинный перерыв 15 мин; звук + вибрация по окончании, счётчик циклов за день
- **Порталы**: «Фемида», электронная библиотека, КонсультантПлюс, Гарант —
  с автоматической заглушкой «Открыть в браузере», если встраивание запрещено
- **Тёмная тема** — переключатель 🌙/☀️ в шапке, выбор запоминается
- **Счётчик в шапке** — «3 пара · до конца 25 мин» / «перерыв · до 13:00»
- **Синхронизация** (JSONBin.io) и **экспорт/импорт** JSON-резервной копии

## Быстрый деплой (бесплатно)

- **GitHub Pages**: залейте файлы в Public-репозиторий → Settings → Pages → Deploy from branch → `main` → `/ (root)`. Сайт будет на `https://<ник>.github.io/<репозиторий>/`
- **Netlify Drop** (30 секунд): перетащите папку с файлами на https://app.netlify.com/drop
- **Vercel**: Add New → Project → импорт репозитория (каждый push обновляет сайт)
- **Cloudflare Pages**: безлимитный трафик, хорош для аудитории из РФ

## Синхронизация между устройствами

Данные (задачи и заметки) по умолчанию живут только в браузере устройства.
Чтобы они появлялись на всех устройствах:

1. Зарегистрируйтесь на **https://jsonbin.io** (бесплатно, без карты; лимит 10 000 запросов/мес — с запасом).
2. В Dashboard скопируйте **X-Access-Key**.
3. В приложении: вкладка **«Ещё»** → вставьте ключ → **«Сохранить»** — Bin ID создастся сам.
4. На втором устройстве введите **тот же ключ и тот же Bin ID** → «Сохранить» → «Из облака».

Логика слияния: задачи объединяются по ID без дублей; при конфликте версия
из облака побеждает, заметки — наоборот, локальные. Включите
**«Автосинхронизация»** — тогда данные сами уйдут в облако через 2,5 секунды
после любого изменения и подтянутся при запуске приложения.

> Безопасность: ключ хранится только в localStorage вашего браузера и отправляется
> только на api.jsonbin.io. Данные в бине защищены ключом (не публикуйте его).
> Кто угодно с ключом и Bin ID сможет прочитать/перезаписать данные — относитесь к ключу как к паролю.

**План Б без регистрации**: вкладка «Ещё» → «Резервная копия» → Экспорт/Импорт JSON-файлом.

## Порталы «Фемида» и библиотека (запрет встраивания)

Вкладки «Фемида», библиотеки, «КонсультантПлюс» и «Гарант» — это iframe на чужие сайты. Если те когда-нибудь
запретят встраивание (заголовок `X-Frame-Options`), сработают три уровня защиты:

1. Кнопка **«Открыть в браузере»** — всегда на виду в шапке вкладки.
2. Если iframe не загрузился за **9 секунд** — автоматически показывается
   полноэкранная заглушка с кнопкой «Открыть в браузере».
3. В настройках («Ещё» → «Порталы») можно включить **«Всегда открывать в браузере»** —
   тогда iframe вообще не грузится, и вкладка сразу показывает кнопку-ссылку.

Там же есть кнопки копирования прямых ссылок на оба портала.

## Установка на телефон (PWA)

Откройте сайт в Chrome (Android) → меню → «Установить приложение».
На iPhone: Safari → «Поделиться» → «На экран "Домой"». Иконка появится на рабочем
столе, сайт откроется в отдельном окне и будет работать без сети
(кроме вкладок «Фемида» и «Библиотека» — они грузят внешние сайты).

## Обновление расписания

Расписание захардкожено в `index.html` в объекте `scheduleData`
(и массив `bells` для звонков). Поменяли пары → отредактировали файл →
запушили → сайт обновился. Чтобы не править код руками, в будущем можно
вынести расписание в отдельный `schedule.json`.

## Важные замечания

- Очистка кэша браузера или смена устройства удалят локальные данные —
  держите включённой синхронизацию или делайте экспорт JSON.
- Лимит бесплатного JSONBin — 100 КБ на бин и 10 000 запросов/мес;
  задач/заметок в несколько тысяч хватит с головой.
