                  Синхронизация между устройствами

                  Задачи, ДЗ и объявления — через Supabase (код группы) или JSONBin.io

                  Данные группы хранятся в облаке и синхронизируются между всеми устройствами. Supabase — нужен только общий код группы (рекомендуется). JSONBin.io — классический вариант с ключом. Введённые значения видны только в вашем браузере.

                  Раздайте этот код одногруппникам — этого достаточно для синхронизации. Первая синхронизация создаст запись в облаке автоматически.
